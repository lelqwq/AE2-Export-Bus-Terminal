# AE2 Export Bus Terminal / ME 输出总线诊断器

针对 **GTNH 2.8.4** 的独立 AE2 附属模组。集中查看当前 ME 网络的物品和流体输出总线配置，按物品/流体搜索，并在世界中高亮具体总线的安装面。

## 版本与安装

| 组件 | 目标版本 |
| --- | --- |
| Minecraft | 1.7.10 |
| Forge | 10.13.4.1614 |
| GTNH | 2.8.4 |
| Applied Energistics 2 GTNH | rv3-beta-695-GTNH（严格锁定） |
| AE2 Fluid Crafting（流体总线支持） | 1.4.120-gtnh（GTNH 2.8.4 自带；可选集成） |
| 本模组 | 1.0.0 |

将 `build/libs/ae2-export-bus-terminal-1.0.0.jar` 同时放入客户端、服务端的 `mods` 文件夹，并移除旧版本 JAR。单人游戏只需装到当前实例。不要安装 `-sources.jar`、`-dev.jar` 或 `-dev-preshadow.jar`。

无需替换 AE2，无需新增前置模组，无 Mixin 或 Coremod。拼音库 PinIn 及其必要依赖已内置并重定位，避免与整合包中的同名库冲突；AE2 和 Minecraft 不会打包进成品。

## 使用

1. 无序合成 **ME输出总线诊断器**：ME输出总线 + 指南针 + 红石粉 + 下界石英。也可在创造模式“工具”分类找到。
2. 手持诊断器，右键主网中的 ME 线缆或设备，绑定该**逻辑 ME 网络**并打开查询。点击线缆上的具体部件时优先使用该部件所属的网络。绑定后到其他维度也能右键空气查询，不再依赖原先点击的线缆或其维度。
3. 搜索框可输入当前语言的物品/流体名称、完整拼音、拼音首字母、注册名（如 `gregtech:gt.metaitem.01`、`steam`）、矿典过滤表达式文本或坐标；多个以空格分隔的词同时匹配。例如：“铁锭”可用 `tieding`、`td` 或 `铁ding`；“不锈钢锭”可用 `bxgd`；“蒸汽”可用 `zhengqi` 或 `zq`。支持大小写混输，并忽略名称中的颜色格式码。拼音基于当前客户端显示的中文名称；英文界面可直接搜索英文名称和注册名。输入“物品”或“流体”可筛选对应总线类型。
4. 滚轮浏览，点击任意结果行：界面关闭，并显示目标总线安装面的透墙线框、方向箭头、距离和坐标。同一线缆方块上的不同面可以分别定位。
5. 右键空气重新查询绑定网络；“刷新”更新快照。“清除定位”移除标记，标记也会在 5 分钟后自动消失。
6. 右上角“排序：名称 / 排序：距离”按钮切换排序，默认名称排序。选择在本次游戏运行期间保留，关闭界面或刷新不会重置，重启游戏后恢复名称排序。搜索只过滤，不改变当前排序规则。

两种排序都先列当前维度，再按其他维度 ID 升序分组。名称排序在每个维度内按当前客户端语言的物品/流体显示名称升序排列（中文采用中文排序规则，英文忽略大小写和名称颜色码）；物品和流体混排。多个配置取名称最靠前的一项，包含变暗槽中保留的配置；未配置任何名称的总线排在该维度末尾。同名时保留原有距离、X/Y/Z、安装面顺序。距离排序完全沿用原规则：同维度按扫描时的三维距离从近到远，再按 X/Y/Z 和安装面；其他维度也按玩家扫描时坐标计算距离，移动后需刷新。

每行标明“物品/流体”类型并显示 9 个过滤槽。流体槽使用实际流体的图标和颜色；悬停显示流体名称及注册名。缺少容量卡而不可用的槽位会变暗；保留的配置仍可被搜索。悬停还可查看红石模式、物品总线的模糊模式/矿典表达式；有合成卡时显示标签。

## 范围和行为

- 只读查询，不修改总线、物品库存、过滤配置、红石模式或升级卡。
- 列出 **AE2 物品 ME Export Bus**、**AE2 Fluid Crafting ME Fluid Export Bus** 及其子类；不列出 GT 的 ME 输出仓、接口或输入总线。不安装 AE2FC 时保留物品总线功能。
- 以 AE2 存档中的持久网络存储编号绑定同一个**逻辑 ME 网络**，支持跨维度查询、存档重载及原点击线缆的移除；不穿过存储总线/接口边界去递归扫描独立子网。需要时在子网重新绑定。
- 扫描 AE2 当前已知且已加载的总线，不强制加载区块或维度。原点击点可以卸载，但绑定网络必须仍有已加载的实例；全部卸载时请先加载该网络。网络解散、分裂或合并可能更换原网络编号，此时需重新绑定。
- 网络没有安全终端时可正常查询；有安全终端时遵守 AE2 的 **BUILD** 权限。
- **在线**只表示 AE2 节点满足供电/频道等条件，不表示正在传输。红石阻止工作、目标容器已满时也可能在线。
- 结果是手动刷新的配置快照，不是历史输出记录。拆除或修改总线后请刷新。高亮来自快照中的位置，期间不会持续核验总线是否仍存在。
- 搜索匹配已配置物品/流体及矿典表达式的**文本**，不枚举模糊卡/矿典表达式能够接受的所有物品。流体配置包中的流体 NBT 会保留；查询不改变配置数量，也不记录实际传输量。
- 查询每个工具最多每秒一次。大型网络逐行传送结果，界面显示接收进度。

### 从 0.1.0 升级

旧工具会在原绑定点已加载时自动迁移为网络绑定，也支持从其他维度触发这次迁移。若原绑定点已移除或未加载，直接右键当前网络任意线缆/设备重新绑定一次即可。迁移完成后不再依赖该位置。

## 构建与检查

在项目根目录运行：

```powershell
.\gradlew.bat test build
```

Gradle 使用 JDK 17+ 运行（建议 JDK 25），插件会选择/下载 Java 8 编译工具链，产物使用 Java 8 字节码。首次构建需要联网下载 Minecraft、Forge、AE2 和 GTNH 构建工具。

源码入口：`src/main/java/dev/exportterminal/`。`ScanService` 负责服务端查询和权限，`TerminalNetwork` 负责快照传输，`client/` 负责界面与高亮。服务端/客户端分别在各自主线程处理世界数据或界面更新。

自动化测试覆盖中文/全拼/首字母/混合搜索、多音字、格式码、系统语言差异、网络编号持久化与解析、旧绑定标识判定、六个安装面的定位边界、快照协议、真实 AE2FC 输入/输出总线类型区分、流体配置包解析及流体名称搜索，以及名称排序的维度优先级、多配置取名、空配置置后与同名稳定顺序。完整游戏验证步骤见 `TESTING.md`。

用户已在自己的 GTNH 环境中测试并确认当前功能可用，发布为 1.0.0。未单独记录专用服务器、多人交互及全部验收步骤的逐项结果；JUnit 无法代替 Forge 完整启动环境。
